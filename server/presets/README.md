# Fixed podcast and speech presets

Run `.venv-tts/bin/python scripts/download_presets.py` from the repository root to install the two preset recordings. The prepared Mac already has them.

- Female: VCTK p225, utterance 023, mic1.
- Male: VCTK p226, utterance 023, mic1.

The download script verifies the original SHA-256 hashes. No uploaded or user-recorded voices are accepted. The files are omitted from Git to keep the repository small. See the root THIRD_PARTY_NOTICES.md for the corpus attribution, source links, and CC BY 4.0 license.
